# 美术生产指南（v3）

> 面向：负责立绘的老师 / 外包画师 / 使用 AI 出图的人
> 配套：`docs/品阶体系-v3-中国风设计规范.md`（视觉与风格光谱）、`scripts/check-art.mjs`（缺口检查）
> 当前缺口：**108 张**（宠物 98 + 角色 10），用 `node scripts/check-art.mjs` 随时复查

---

## 一、要画什么（先看清单，别看需求文档）

| 类别 | 数量 | 说明 |
|---|---|---|
| 宠物立绘 | **98** | 万象 24×2 = 48；八卦 8×3 = 24；四象 4×4 = 16；太极 2×5 = 10 |
| 角色立绘 | **10** | 男/女基础各 1 + 校服/汉服/节气/结业 各 2 |
| 活动横幅 | 4 | 可选，缺省时用渐变占位 |
| 图标 | 0 | 卦象直接用字体符号 ☰☷☳☴☵☲☶☱，不用画 |

**不需要画的**：无极（学生自造）、宠物皮肤（已删除）、UI 边框/卷轴/印章（纯 CSS 已实现）。

### 规格（硬性）

| 项 | 要求 |
|---|---|
| 尺寸 | 1024×1024；角色 1024×1536 |
| 格式 | **PNG-24 透明底**（不要白底、不要淡紫底） |
| 构图 | 全身，正面或微侧，主体高占 **72%**，底边留 8% |
| 描边 | 6–10px 闭合粗描边（暗底上要立得住） |
| 体积 | 单张 ≤ 250KB（可用仓库的 `compress-images.sh` / `convert-webp.sh` 压） |
| 命名 | `public/pets/{id}/form{N}.png`、`public/characters/{skin}.png`（`check-art.mjs` 按此校验） |
| 禁止 | 水印、文字、场景、地面投影、多主体 |

## 二、工具推荐（按你的条件选一条链）

> 工具版本与价格变动快，下表只讲**能力与取舍**，具体以官网为准。

### 方案 A｜零成本本地（有独显、愿意折腾）

| 环节 | 工具 | 理由 |
|---|---|---|
| 出图 | **ComfyUI + SDXL / Flux.1-dev** | 批量、可复现、完全免费；配国风 LoRA 出图风格稳定 |
| 风格锁定 | 国风/工笔 LoRA（Civitai 上有现成） | 一次训练或直接下载，比提示词可靠 |
| 抠图 | **BiRefNet** 或 `rembg`（`isnet-anime` 模型） | 动漫风格边缘干净，比魔棒好太多 |
| 放大 | Real-ESRGAN | 批量放大到 1024 |
| 适合 | 一次要出 100 张、且要统一风格 | |

**代价**：要 8G+ 显存、装环境、调采样；出图好看与否取决于 LoRA 选得对不对。

### 方案 B｜国内在线工具（推荐给老师本人）

| 环节 | 工具 | 理由 |
|---|---|---|
| 出图 | **即梦 Seedream**、**可图 Kolors**、**通义万相**、文心一格 | 中文提示词友好、国风水墨理解好、按张付费或无免费额度 |
| 一致性 | 用「参考图」/「风格参考」功能锁定前 3 张锚图 | 比纯提示词稳；但跨角色一致性弱于 MJ |
| 抠图 | 各平台自带「移除背景」，或 **佐糖**、**Photoroom** | 一键，边缘可接受 |
| 适合 | 不想装环境、要快、以「能看」为目标 | |

**代价**：角色一致性一般，同一只宠物的 2–5 个形态容易画成「不同的兽」，需要人工挑图 + 参考图迭代。

### 方案 C｜付费专业（追求一致性与质感）

| 环节 | 工具 | 理由 |
|---|---|---|
| 出图 | **Midjourney v7**（`--sref` 风格参考 + `--cref` 角色参考） | 目前**跨图一致性最强**的一档，适合「同一只宠物多形态」 |
| 图标/UI 素材 | **Recraft**（矢量、可导出 SVG） | 需要新图标时最快 |
| 精修 | Photoshop / Affinity | 描边统一、修边缘、补细节 |
| 动画（二期） | **Rive**（免费 web runtime）或 Spine | 立绘动起来（呼吸/施法），见 `docs/战斗引擎选型.md` |
| 适合 | 预算有限但要求成品级 | 约 $10–30/月 |

## 三、一致性：这是全项目最难的一步

同一只宠物要出 2–5 个形态（初相→化相→法相…），**不能让它们看起来像不同物种**。三个办法按可靠度排序：

1. **Midjourney 角色参考（`--cref`）+ 固定描述骨架**
   - 第一段永远写「同一只 {宠物名}，{固定的外观描述}」——这段**一个字都不要改**；
   - 只改第二段「形态」：`初相：小体型，无附加物` / `化相：+飘带与金色纹路` / `法相：+须弥座与双环`；
   - `--sref` 挂同一张风格锚图，保证画风不飘。
2. **LoRA / IP-Adapter（本地方案）**：把 3 张锚图训一个 15–30 分钟的小 LoRA，之后所有形态都带它。
3. **先画设定表**：手绘三格草图（体型比例、配色、配件），再逐格出图。慢但最稳。

> **风格锚图建议**：先用现有素材里最符合 v3 调性的两张当锚 —— `public/pets/white-tiger/lv7.png`（俊萌交叉）与 `public/pets/tiger/lv7.png`（雅致星河）。锚图只做风格参考，**不要直接当成品**（它们是旧体系素材）。

## 四、分风格提示词模板

先定风格，再套模板。四类的差异见 v3 设计规范 §7.4。

### 通用骨架

```
主体：{宠物名}，{固定外观：体型/毛色/角/尾/翼/鳞}，全身，正面微侧，
      中国工笔重彩 + 水墨点缀，闭合粗描边，宣纸颗粒质感。
形态：{初相 | 化相 | 法相} —— {本形态差异}
配色：{本风格配色要点}，明度不低于 45%，暗部同色系压暗。
背景：纯透明背景（PNG），无场景、无地面、无水印、无文字。
构图：主体高度占画布 72%，底边留 8%，居中。
```

### 四类风格要点

| 风格 | 追加描述 | 负面词（必加） |
|---|---|---|
| **萌系** | 头身比 1:1.3，圆脸大眼，短肢圆肚，2–3 个眼高光，腮红 | 尖牙、肌肉、写实、恐怖、写实毛发 |
| **俊逸** | 头身比 1:2.7，修长挺胸，刀锋轮廓，金属边（石青/黛），眼神锐利 | 圆滚滚、幼态、胖、卡通 |
| **雅致** | 头身比 1:2.5，流线 S 形，长尾羽/水袖，半透明质感，低饱和渐变 | 粗壮、脏色、灰暗、低明度 |
| **奇诡** | 头身比 1:2，非对称，多首/多目/异肢，撞色（紫/墨绿），但有秩序 | 血腥、内脏、骷髅、惊悚、恶心 |

**所有风格共用的负面词**：`watermark, text, signature, background scenery, ground shadow, multiple characters, blurry, low contrast, muddy colors`。

## 五、生产流程（建议按此顺序，别一次性铺开）

```
1. 出风格锚图 3 张（四象各 1：青龙/白虎/朱雀/玄武）
2. 人工选 1 张定稿 → 用它做 --sref 或训 LoRA
3. 先做「四象 4 只 × 首形态」= 4 张 → 作为全项目标杆
4. 批量出「八卦 8 只 × 首形态」= 8 张 → 检查 64px 缩略是否可辨
5. 补齐各阶第 1 形态（万象 24 + 太极 2）
6. 再按「先高品阶、后万象」补第 2–5 形态
7. 每批跑一次 node scripts/check-art.mjs，并在 /teacher/content 点「检查立绘缺失」
8. 全部到位后跑 compress-images.sh 压体积，再 build
```

**为什么先做四象**：数量少（4 只）、形态多（4 阶）、最能暴露风格问题；改 4 张比改 98 张便宜。

## 六、验收清单（每张图过一遍）

- [ ] 透明底，无白边/紫边；缩到 64px 仍认得出是这只
- [ ] 主体高 72%、底边 8%，与同宠物其他形态**基线对齐**（切换形态时不会跳）
- [ ] 明度 ≥ 45%，暗部同色系压暗（没有脏灰）
- [ ] 描边闭合、粗细一致（6–10px）
- [ ] 风格对位（萌/俊/雅/奇 是哪种，别混）
- [ ] 同一宠物多形态：脸、配色、标志性特征一致
- [ ] 不血腥、不恐怖、不性感化
- [ ] 无水印、无文字、无场景
- [ ] 命名与目录正确（`check-art.mjs` 通过）

## 七、工时与成本（粗估）

| 方案 | 108 张预计 | 成本 | 风险 |
|---|---|---|---|
| A 本地 ComfyUI | 2–3 周（含调环境） | 0（电费+显卡） | 学习曲线、LoRA 调不好风格飘 |
| B 国内在线 | 1–2 周 | 几十到几百元 | 一致性弱，需人工挑图返工 |
| C Midjourney + PS | 1–2 周 | $30–60（月费+返工） | 依赖 `--cref` 效果，仍需精修 |

**给现实建议**：**方案 C 出图 + 方案 A/B 兜底**。先用 MJ 把 4 只四象做成标杆（约 16 张），确认风格后，剩下的用本地批量跑，成本最低。

---

## 八、不要这么做

| 不要 | 原因 |
|---|---|
| 一次生成 98 张 | 风格会飘，返工量大于分批 |
| 让 AI 带背景出图、再由前端抠 | 边缘永远不干净，暗底上会有一圈白边 |
| 混用多个模型出同一只宠物的不同形态 | 同一只兽会被画成两种物种 |
| 只用提示词不做参考图 | 一致性完全失控 |
| 出图后直接放大到 1024 | 细节崩坏，尤其眼睛与描边 |
| 画宠物名（汉字）在图上 | 注音与名字由 UI 渲染，图里写字会重复且不可改 |
