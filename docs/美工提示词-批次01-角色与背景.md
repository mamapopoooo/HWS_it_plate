## 0. 即梦操作步骤（照这个来）

1. 打开「图片生成」，模型选 **图片 4.0**（没有就 3.0），一次生成 **4 张**；
2. 比例：角色 **3:4**，背景 **16:9**；
3. 先只生成**第 1 张「风格锚」**（大厅背景），满意后把它上传到「参考图」，强度调 **0.55–0.7**，再生成其余图 —— 这是保持整套画风一致最省事的办法；
4. 每张挑 1 张后点「超清」放大到 2K，再导出 PNG；
5. **角色立绘必须去背景**：用即梦自带的「抠图」或本地 BiRefNet，导出透明 PNG；
6. 命名与存放见本文第 5 节，放好刷新页面即生效，无需改代码。

**通用负面词（每张都粘，放在「反向提示词」框）**

```
文字, 水印, logo, 签名, 边框, 多余人物, 双人, 现代建筑, 汽车, 电线, 照片写实, 3D渲染, 塑料质感, 过饱和, 荧光色, 脏灰, 血腥, 伤口, 骷髅, 内脏, 恐怖, 惊悚, 裸露, 性感, 低清, 模糊, 畸形手指, 多手多脚
```

## 1. 男主 · 素衣（`base_m`）

**要什么**：12 岁上下、少年向、清秀利落、中国风素衣，全身站姿，纯色浅底便于抠图。

```
全身立绘，中国风二次元少年，12岁，清秀清瘦，黑色短发用青灰发带束起，细眉大眼，温和自信的浅笑；
身穿素白交领右衽长衫，衣料为麻棉质感、有细密竖纹，外披一件浅青灰对襟短褂，腰系青灰布带，脚穿黑布鞋，袖口与衣摆有简单云纹暗花，无任何暴露；
正面微侧身站姿，双手自然垂放，一只脚略前，重心稳；
中国工笔重彩结合水墨画法，人物有6到10像素闭合粗描边，宣纸颗粒质感，柔和顶光，颜色控制在素白、青灰、朱砂点缀；
纯浅暖灰背景，无阴影无场景；
人物高度占画面90%，头顶留白4%，脚底留白6%，居中；
竖构图3比4。
```

**变体提示（同一角色，改最后一句即可）**
- 表情：`微笑` → `开心大笑，眼睛弯成月牙` / `认真，眉头微蹙看向前方`
- 姿态：`双手垂放` → `一手负后，一手轻抬示意`

## 3. 背景 · 大厅（`lobby`，先做这张当风格锚）

**要什么**：像一张铺开的宣纸，**中间大片留白**给宠物站台，四周有山水，不能抢戏。

```
中国水墨山水背景，横构图16比9，宣纸底色（暖米黄），远山以淡墨层层叠压、近处山石略深，山间留白云雾；
画面正中大面积留白（占中部约60%区域，不放任何主体，供叠加角色立绘）；
左下角两株松枝与一方山石，右上角淡云与一轮浅金月，四角极淡的朱砂印章痕迹但无文字；
整体明度高、对比柔，只有墨灰、米黄、朱砂三种色系；
中国工笔淡彩加纸纹质感，细腻纤维可见，无任何人物、无任何文字。
```

## 5. 交付规格与放置路径

| 资产 | 文件名 | 尺寸 | 格式 |
|---|---|---|---|
| 男主素衣 | `public/characters/base_m.png` | 竖 3:4（1024×1365 起） | PNG 透明 |
| 女主素衣 | `public/characters/base_f.png` | 竖 3:4（1024×1365 起） | PNG 透明 |
| 大厅 | `public/backgrounds/lobby.png` | 横 16:9（2400×1350） | PNG 或 JPG ≤400KB |
| 登录 | `public/backgrounds/login.png` | 横 16:9 | 同上 |
| 斗法 | `public/backgrounds/duel.png` | 横 16:9 | 同上 |
| 集市 | `public/backgrounds/market.png` | 横 16:9 | 同上 |

**角色图会被显示在 180×260 的框里（约 3:4）**，所以构图务必：人物居中、头顶不超过 4%、脚底留 6%，否则切换时会"跳"。

背景是叠加在页面最底层的，**中央留白越干净越好**，卡片、卷轴、宠物都压在上面。

## 6. 出图后自检（10 秒版）

- [ ] 角色：透明底干净、缩到 64px 仍认得出是男生/女生
- [ ] 角色：校服/素衣覆盖肩膝，**无暴露、无性感化**
- [ ] 描边闭合、粗细一致（6–10px），无断线
- [ ] 同一套里明度一致，没有一张特别暗或特别亮
- [ ] 背景：中央留白够大，没有山尖/树梢穿过中间
- [ ] 背景：没有任何文字与印章文字（印章只能是色块痕迹）
- [ ] 无血、无伤、无骷髅、无恐怖元素
- [ ] 体积：背景单张 ≤400KB（可用仓库 `compress-images.sh`）
