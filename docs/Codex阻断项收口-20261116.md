# Codex阻断项收口（2026-11-16）

本批仅整合分支开发，未部署、未改真实数据库/账号或开启管控上传。

## 年级榜

`GET /api/v3/rankings/:id`：可选grade只允许字符串6或7；非法、空值、重复参数返回400。不传仍兼容原全年级查询。grade作用于年级榜，筛选在分组和窗口排名前执行，采用参数绑定。points/power/collection_rate三指标均回归；未知指标400，未知榜404。修正旧版GROUP BY后追加AND及NaN拼接导致500/筛选错误。

## 管理员初始化

迁移不再创建硬编码默认管理员；启动完成schema准备后，统一调用bootstrapAdmin。库内已有admin则不覆盖凭据。无admin时必须通过运行环境显式提供ADMIN_USERNAME与ADMIN_PASSWORD，密码至少12位且含字母及非字母；用户名占用、配置缺失/无效均阻止服务继续启动，不泄露密码。生产使用部署秘密配置提供变量，勿把真实值写入仓库或聊天。

这改变新库启动前提：以前依赖默认口令的本地脚本必须改为显式虚构测试凭据，或在隔离库显式创建测试管理员。已有库的历史弱密码不会自动重置，管理员仍需另行更换；本批没有连接生产验证或更改它们。密码哈希算法沿用现有验证器，本批未迁移旧哈希。

## 教师积分

`POST /api/v2/teacher/sync-points`沿用admin鉴权，接收1～200条records，每条必须有稳定eventId、studentNo、amount、reason。eventId为16～128位字母/数字/下划线/连字符；金额为非零安全整数且绝对值不超过10000，原因不超过200字符。学号字符串不转数值，必须对应现有名单和非游客student账号；全局管理员权限仍按旧角色模型，未新增跨学校租户权限。

增量表teacher_point_events持久保存eventId、提交者及规范请求体；首次应用、余额更新、名单累计total_points、game_points_records和去重记录同事务。重复事件同教师同内容返回duplicate；同ID换内容/教师返回409。整批任一非法学生、余额不足或数据库写入错误则全批回滚。消费只改game_points，教师积分变更才同步累计字段；本接口不对既有累计数据回填，也不重新按年级倍率加分。

金额可正可负，按原接口加减语义处理；不允许写出负余额、不把不足部分截成0。负分/撤销的完整产品规则及自动反向事件仍待独立定案，本批未启用管控负分/撤销上传。无效结构400、权限403、业务冲突409；没有部分成功，成功响应保留success/synced，并追加逐条results[{eventId,status:applied|duplicate}]。旧客户端缺eventId会显式400，不能再按旧success猜已记账。

TeacherDesk按教师userId隔离本地待提交队列，先持久保存事件再提示待提交；不提前变更显示余额。提交期间截取批次，收到完整逐条ACK后仅移除该批事件并重新读服务端余额；同时新加的记录保留。错误/丢响应/重开页面保留事件ID，人工重试由服务端去重；身份切换禁止提交旧队列。浏览器存储不可写时不接收新事件。未增加自动后台上传、capability接口或管控集成；本地存储被用户清除/换设备无法恢复未提交队列，服务端无权认定这些记录已送达。
