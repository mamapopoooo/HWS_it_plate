三形态的具体差异 美术要遵守的四个递进维度

同一只宠物必须能认出是同一只，只在 体型 / 配件 / 配色 / 光 四个维度上递进。下面是现有素材的实例关系。

FORM 1

初始形态 · 幼崽

体型 100%　配件 无

配色 原色，无第二强调色

光 无自身光

→ form1.png（或复用 lv1.png）

FORM 2

共鸣形态 · 壮虎

体型 112–115%　配件 +1（体型/肌理）

配色 主色不变，饱和度 +12%，金瞳出现

光 体表微光 + 一层光环

→ form2.png（或复用 lv4.png）

FORM 3

究极形态 · 星空神兽

体型 130–135%　配件 +3（光环/飘带/星纹）

配色 主色保留 60% + 金/紫金属色

光 自身发光（身体里有光，不是外圈光）

→ form3.png（或复用 lv7.png）

关键一步：现有图是 1024×1024 JPEG + 淡紫平底 + 右下角水印，直接贴到深空背景上会露出一个淡紫方块。 稿里用 CSS 径向遮罩 + 光台把方角糊掉了，这只是过渡办法 —— 正式美术必须出 PNG-24 透明底、无水印、主体高 72% 的图，否则换形态时宠物会忽大忽小、边缘发虚。
