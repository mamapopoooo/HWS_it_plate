# 内容安全红线（未成年人保护）

> 适用对象：**所有内容输入方** —— 老师、画师、AI 出图、学生造物、文案撰写者。
> 本项目面向 **11–14 岁中小学生**，目标分级：**全年龄 / 儿童向**（对标 PEGI 7）。
> 本文件优先级高于任何"忠于古籍原文""追求视觉冲击"的诉求。

---

## 一、三条绝对红线（出现即退回，无讨论余地）

### 1. 色情与性化

**禁止**：裸露、透视、性暗示姿势、刻意强调身体曲线、内衣/泳装式着装、萝莉/正太擦边。

**允许**：正常少年向体型、校服、汉服、飘带与衣纹。

> 角色立绘一律**少年向 1:4.5 头身**，校服**覆盖肩膝**；"可爱"与"美丽"靠颜色、线条、配件达成，不靠暴露。

### 2. 血腥与暴力细节

**禁止**：血液、伤口、断肢、内脏、捕食/撕咬场面、痛苦扭曲的表情、武器刺入身体。

**允许**：獠牙、尖角、利爪（不出血）、战斗中的光效与冲击波、倒地（无伤可见）。

> 斗法是"术法对决"，不是屠宰。伤害用**光效、数字、震动**表达，不画伤口。

### 3. 恐怖与惊悚

**禁止**：骷髅、腐尸、蛆虫、扭曲人面、惊悚贴脸、精神污染式构图、自伤/自杀暗示。

**允许**：多目、多首、异肢（山海经本色，但要**有秩序、不恶心**）、幽光、雾。

## 二、山海经原文的改写原则（本项目已按此整改）

古籍里有大量「食人」「食虎豹」「见则大旱/大水」的凶性描述。**保留文化出处，但把"捕食"改成"性情/职责"**：

| 原文倾向 | 改写方向 | 已改示例 |
|---|---|---|
| 食人 | 性烈 / 守山径 / 不让人过 | 犀渠：~~食人~~ → 性烈，守山径不让人过 |
| 食人 | 护山草木 | 土蝼：~~食人~~ → 守护山间草木 |
| 食虎豹 | 能驯猛兽 | 驳：~~食虎豹~~ → 能驯猛兽 |
| 死/杀 | 藏 / 见 / 收 | 鯥：冬~~死~~夏生 → 冬藏夏见；白虎：主秋~~杀~~ → 主秋收 |
| 贪食无厌 | 贪吃成性（可带喜感） | 饕餮：~~贪食无厌~~ → 贪吃成性 |

**判断标准**：这段文字如果念给四年级学生听，老师会不会尴尬？会，就改。

## 三、视觉上的"收敛但保留神韵"

| 元素 | 可以保留 | 必须收敛 |
|---|---|---|
| 牙齿 | 小虎牙、露齿笑 | 血盆大口、滴血、撕咬 |
| 眼睛 | 多目、异色瞳、竖瞳 | 眼球突出、眼白过多、惊悚凝视 |
| 骨/甲 | 甲片、骨纹**化用为云纹/岩纹** | 白骨、骷髅、内脏外露 |
| 肢体 | 多尾、异肢、翼 | 断肢、扭断的关节、触手（易引发不适） |
| 效果 | 墨色、金光、雷弧 | 血雾、肉块、液体飞溅 |

> 奇诡风格（`qi`）是**最容易被画过头**的一类。它的"奇"来自**结构异常**（多首、无面、异比例），不来自"恶心"。

## 四、学生造物（无极 UGC）的审核

学生可以自己上传立绘并命名，因此**教师审核是最后一道闸**。审核页（`/review`）已内置四项合规勾选，**四项全勾才能点「通过」**：

1. 不含色情或性暗示
2. 不含血腥、暴力、内脏
3. 不含恐怖惊悚元素
4. 不含本人或他人隐私信息（真实姓名、电话、照片、住址）

**额外检查**：
- 名称与注音是否得体（避免脏话谐音、侮辱性词汇）；
- 是否直接盗用他人作品（同学之间抄袭）；
- 若驳回，**必须写理由**，理由会展示给学生。

## 五、违规内容的处置

| 场景 | 动作 |
|---|---|
| 审核阶段发现 | 直接驳回，写清理由，学生可修改后重提（最多 3 次） |
| 上线后发现 | 教师可一键下架（`custom_pets.status = 'rejected'`），并保留 `audit_logs` 记录 |
| 涉及真实个人信息 | **立即下架 + 通知班主任**，不入库保留 |
| 反复违规 | 暂停该生造物权限，由教师决定恢复时间 |
