## 三、代码状态：v2 前端已清零

`src/pages/v2/`、`src/layouts/`（AdminLayout / StudentLayout）、`/student`、`/admin`、`/preview` 路由与 v1 三页均已于 2026-11-04 删除。

| 曾经的 v2 能力 | 现在在哪 |
|---|---|
| 登录 | `/login`（v3 国风登录页，复用同一 authStore） |
| 班级管理 / 学生增删改 / 批量导入 | `/teacher` 教师工作台 |
| 积分流水 | `/teacher` 的「积分流水」面板 |
| 数据统计 | `/teacher` 顶栏统计（人数 / 人均 / 最高 / 最低 / 今日） |
| 学生端 8 个页面 | v3 学生端 12 个页面 |
| 宠物 / 皮肤 / 任务 / 成就管理 | `/teacher/content` 内容台账（只读 + 立绘缺失检查） |

**前端现存路由共 18 条**：1 个登录 + 12 个学生端 + 5 个教师端（`/teacher`、`/teacher/content`、`/review`）+ 2 条 v1 重定向（`/` → `/lobby`、`/battle` → `/duel`）。

**后端仍保留 v1 与 v2 的 API**（`/api/*`、`/api/v2/*`）：前端 adapter 依赖它们，等 KIMI/Qoder 统一到 v3 契约后再下线。

## 四、怎么判断一份文档是否还可用

1. 看它有没有提到「6 属性 / 1–6 星 / 宠物皮肤」——有，就是 v2 及以前；
2. 看它有没有提到「五阶 / 八卦 / 对宫 / 无极造物」——有，才可能是 v3；
3. 拿不准就查本表，或直接以 `docs/00-总纲` 为准。
