## 三、还没迁到 v3 的代码（不是文档）

| 位置 | 现状 | 说明 |
|---|---|---|
| `src/pages/v2/Login.vue` | v2 皮肤 | **登录是唯一入口，必须先保留**；换皮即可，别删 |
| `src/pages/v2/student/*`（8 页） | v2 皮肤 | 与 v3 学生端功能重合，待下线或迁移 |
| `src/pages/v2/admin/*`（7 页） | v2 皮肤 | 班级管理、学生导入、数据统计等**v3 还没有的教师功能**，不能直接删 |
| `src/layouts/StudentLayout.vue` / `AdminLayout.vue` | v2 皮肤 | 承载 v2 路由外壳 |

> **结论：v2 代码不能"一刀删"。** 先补齐 v3 侧的「登录 + 班级管理 + 学生导入 + 统计」，再下线 v2 页面与路由。

## 四、怎么判断一份文档是否还可用

1. 看它有没有提到「6 属性 / 1–6 星 / 宠物皮肤」——有，就是 v2 及以前；
2. 看它有没有提到「五阶 / 八卦 / 对宫 / 无极造物」——有，才可能是 v3；
3. 拿不准就查本表，或直接以 `docs/00-总纲` 为准。
