## 一、学生登录（接口实测）

接口：`POST /api/auth/student/login`，body `{ studentNo, realName }`
实现：`server/utils/studentLogin.js`（`createStudentLogin`）—— 学号定位、中文名或英文名归一化后任一匹配、名单外不建号、身份冲突不合并。

| # | 用例 | 期望 | 实测 | 结果 |
|---|---|---|---|---|
| L1 | 中文名正确 | 200 + `role=student` | 200 | ✅ |
| L2 | 英文名正确（`TestJia`） | 200 | 200 | ✅ |
| L3 | 英文名带空格与大小写（` testjia `） | 200（归一化） | 200 | ✅ |
| L4 | 学号存在但姓名错误 | 401 | 401 | ✅ |
| L5 | 学号不存在 | 401（不建号） | 401 | ✅ |
| L6 | 姓名留空 | 400 | 400 | ✅ |
| L7 | 历史 `stu_990002` 身份已存在 | 409（需教师核对，不自动合并） | 409 | ✅ |
| L8 | 裸学号被教师账号占用（`990003` role=admin） | 409 | 409 | ✅ |

**复现命令（PowerShell，服务需在 3004）**

```powershell
$body = @{ studentNo='990001'; realName='TestJia' } | ConvertTo-Json
Invoke-RestMethod 'http://127.0.0.1:3004/api/auth/student/login' -Method Post -Body $body -ContentType 'application/json'
```

**发现一个需要 Codex 记录的实现细节**：`POST /api/v3/roster/students` 建学生时会**同时创建 `users` 行**（`username=学号`、`role=student`）。因此"教师账号占用学号"这一冲突无法通过 roster 接口自然产生，必须手工构造才能复现（我通过直接把该行 role 改为 admin 构造）。这不是缺陷，但**迁移/合并时要按这条事实盘点身份**。
