### 2.1 克制关系：用「对宫相冲」，不用五行相生相克

先天八卦的**对宫**天然成四对，正好当克制表，KIMI 不需要额外发明规则：

| 对宫对 | 说明 |
|---|---|
| 乾 ☰ ↔ 坤 ☷ | 天 冲 地 |
| 震 ☳ ↔ 巽 ☴ | 雷 冲 风 |
| 坎 ☵ ↔ 离 ☲ | 水 冲 火 |
| 艮 ☶ ↔ 兑 ☱ | 山 冲 泽 |

```js
// 对宫互冲 ×1.3，其余 1.0。
// 注意 opposite 是互指的，所以相冲是双向的 —— 不存在单向的「被克 ×0.77」。
const OPPOSITE = { 乾: '坤', 坤: '乾', 震: '巽', 巽: '震', 坎: '离', 离: '坎', 艮: '兑', 兑: '艮' }
const coefficient = (atk, def) => (OPPOSITE[atk] === def ? 1.3 : 1.0)
```

> 早期版本写过「被克 ×0.77」，但 `opposite` 互指决定了那条分支不可达（双方会同时命中 1.3）。
> 2026-11-03 由单测发现并改为单向 1.3；若日后需要攻防差异，应新增 `beats` 单向字段而不是复用 `opposite`。

**为什么选对宫而不是五行**：五行是 5 个属性，你要的是 8 个；硬套五行会出现两个属性无克制关系。对宫是 8 对 8，四对四冲，完整且对称，学生也容易记（"站在对面就打不过"）。

四象与阴阳**双属性/全属性**：
- 四象各主 1–2 卦：青龙 = 震+巽，白虎 = 乾+兑，朱雀 = 离，玄武 = 坎；
- 太极（阴阳鱼）：**全八属性**，不受克制（只吃自己 0.85 的减伤），强但不至于无敌；
- 无极（造物）：全属性 + 每回合免疫一次控制；技能由学生从效果池组合、教师审核。

### 4.1 从「深空科幻」换成「水墨宣纸」

| 层 | v2（赛尔号） | v3（中国风） |
|---|---|---|
| 背景 | 深空星云 + 星点 | **宣纸底 + 水墨远山 + 云雾 + 落款印章** |

### 4.3 字体

```css
--font-title: 'KaiTi', 'STKaiti', 'Kaiti SC', 'Songti SC', serif;  /* 标题：楷体 */
--font-body:  'Songti SC', 'STSong', 'Noto Serif SC', Georgia, serif; /* 正文：宋体 */
--font-num:   'Georgia', 'Times New Roman', serif;                  /* 数字：衬线，tabular-nums */
```

Windows 自带 `KaiTi`/`SimSun`，无需引入 webfont，也不增加体积。标题一律楷体 + 轻微字距（`letter-spacing: .06em`），这是"国风"最廉价也最有效的信号。

### 4.4 图形语言（全部可用 CSS/SVG 实现，无图片依赖）

| 元素 | 实现 |
|---|---|
| 太极图 | 两个半圆 + 两个小圆（CSS），或 SVG path |
| 八卦方位盘 | 8 个卦象字符 `☰☷☳☴☵☲☶☱` 环形排布，`transform: rotate() translate()` |
| 云纹角花 | CSS 多重 `radial-gradient` 叠出的如意云，或 8px 内联 SVG |
| 回纹边框 | `repeating-linear-gradient` 双向 × 4 边 |
| 落款印章 | 正方形 + 圆角 4px + 朱砂底 + 白色篆意文字，`transform: rotate(-6deg)` |
| 水墨晕开 | `radial-gradient` 遮罩 + `scale` 由 0.2 → 1.6 + 模糊 |
| 卷轴 | 上下两端木轴（线性渐变 + 圆角）+ 中间纸面 |

## 7. 美术生产规范（中国风）

### 7.1 输出规格（在 v2 基础上追加国风约束）

| 项 | 要求 |
|---|---|
| 尺寸 | 1024×1024，PNG-24 **透明背景**，单张 ≤ 250KB |
| 风格 | **中国工笔重彩 / 水墨结合**；粗描边（8–10px）便于抠图与暗底辨识 |
| 构图 | 全身，正面或微侧，主体高 72%，底边留 8% |
| 配色 | 遵守 §4.2 国风色板：石青/石绿/朱砂/藤黄/赭石/墨，**禁止荧光色与欧美卡通高饱和** |
| 纹理 | 允许宣纸颗粒、金线勾边（1–2px）、云纹底烘托，但**不得带场景与地面** |
| 禁止 | 文字 / 水印 / 边框 / 场景 / 多主体 / 现代元素（霓虹、机械） |

### 7.2 提示词模板

```
主体：{名称}，出自《山海经·{篇目}》，{外形描述：体型/角/尾/翼/鳞}，
      中国工笔重彩风格，金线勾边，宣纸颗粒质感，国风配色（石青 石绿 朱砂 赭石 藤黄）。
形态：{初相 | 化相 | 法相} —— {本形态差异}
背景：纯透明背景（PNG），无场景、无地面、无文字、无水印、无边框。

禁止：现代元素、荧光色、欧美卡通、多主体、文字。
```

### 7.4 风格光谱：萌 / 俊 / 雅 / 奇

> **为什么这么定：** 全班男女各半，任何"统一画风"都会劝退一半人。所以**不是把宠物都画可爱**，而是让 38 只里萌、俊、雅、奇各有配额 —— 男生能在俊与奇里找到"帅"，女生能在萌与雅里找到"想要"，交叉区间（俊美、奇萌）是意外惊喜。
>
> 每只宠物的风格写在 `docs/seeds/pets.json` 的 `style` 字段（`meng` / `jun` / `ya` / `qi`），美术按下表的比例规则取参。

#### 当前配额（38 只）

| 风格 | 代码 | 数量 | 占比 | 定位 |
|---|---|---|---|---|
| **萌系** | `meng` | 8 | 21% | 幼态、圆润、呆，负责"想抱走" |
| **俊逸** | `jun` | 10 | 26% | 修长、锐利、帅气，负责"想成为" |
| **雅致** | `ya` | 10 | 26% | 流线、飘逸、仙气，负责"想收藏" |
| **奇诡** | `qi` | 10 | 26% | 多首异肢、山海经本色，负责"猎奇" |

**平衡规则（校验脚本会检查）**：每阶至少 2 种风格；同阶内单种风格 ≤ 50%；萌系不低于 15%（否则"可爱感"消失）。

#### 四种风格的画法参数

| 项 | 萌 meng | 俊 jun | 雅 ya | 奇 qi |
|---|---|---|---|---|
| 头身比 | **1 : 1.2 ~ 1.5** | 1 : 2.5 ~ 3 | 1 : 2.2 ~ 2.8 | 1 : 1.8 ~ 2.2 |
| 眼睛 | 占脸宽 ≥1/3，圆，2–3 高光 | 细长上挑，单点高光 | 半阖 / 长睫，柔光 | 可多目，但每目都有高光 |
| 体态 | 短肢、圆肚 | 修长、挺胸、肩线明确 | 流线、S 形、长尾羽 | 非对称、异肢、多尾 |
| 轮廓 | 近乎全弧线 | 直线 + 锐角（刀锋感） | 长弧线 + 飘带 | 弧线为主 + 少量尖角点缀 |
| 配色 | 高明度暖色，粉/奶黄/浅青 | 冷色深调 + 金属边（石青/黛） | 低饱和渐变 + 半透明质感 | 撞色 + 一点反常色（紫/墨绿） |
| 明度 | **70–85%** | 40–60% | 55–75% | 45–70% |
| 适合的元素 | 铃铛、肉垫、腮红 | 角、刃、甲、披风 | 羽、纱、水袖、光晕 | 骨纹、多目、缠绕 |
| 参考现有素材 | `white-tiger/lv1` | `white-tiger/lv7`（加冠+翼=俊萌交叉） | `tiger/lv7`（星河神虎） | `tiger/lv1`？否，需多首异肢 |

#### 全局底线（四种风格都必须满足）

- **明度不低于 45%**，暗部用同色系压暗，不用黑灰（黑灰显脏）；
- **64px 缩略图仍能辨认**（图鉴会缩到 64px）；
- **不血腥**：可有獠牙、尖角（俊/奇允许），但**不出现伤口、内脏、血**；
- **不恐怖**：允许异形（多目、多首），不允许骷髅、惊悚表情；
- **不幼态化到失去辨识**：萌系也要保留该宠物的标志性特征（九尾狐的九尾必须看得出来）；
- 立绘边缘留 1–2px 暖白柔光，贴在任何深色 UI 上都不"埋边"。

#### 角色（性别各一套，同一套风格口径）

- 头身比 **1 : 4.5**（少年向，不画成人比例）；
- 男女都走"清秀可爱 + 利落"的中性路线，**不画过度性感**（校服覆盖肩膝）；
- 表情 ≥ 3 个：平常 / 笑 / 认真；
- 待机动作：眨眼 4–6s、发梢/衣角轻摆 3s、呼吸缩放 3.4s。

#### 表情与待机（所有风格通用）

- 每只宠物 ≥ **3 个表情**：平常 / 开心 / 战斗；
- CSS 可实现：眨眼、摇尾、歪头、呼吸缩放 —— 不需要逐帧；
- **禁止面无表情的"证件照"式立绘**，这是现有素材最普遍的问题。

#### 评审：先分风格，再打分

1. 这只宠物的 `style` 标注是哪种？（先确认，别用错标尺）
2. 它符合该风格的**头身比与明度**区间吗？
3. 缩到 64px 还认得出是这只吗？
4. 表情有情绪吗？
5. **同阶其他三只的风格和它明显不同吗？**（避免整阶一个画风）
6. 目标受众自测：男生看俊/奇会不会觉得帅，女生看萌/雅会不会想收集？

#### 注音：与宠物名绑定，不单独维护

山海经名字里生僻字很多（猼訑、鵸鵌、鴸、鯥、讙、羬羊、蠃鱼、鸓…），11–14 岁的学生大多读不出来。规则只有一条：

> **注音是宠物记录的一个字段，跟着名字走，别处不许另存一份。**

- 数据：`docs/seeds/pets.json` 每只宠物都有 `pinyin` 字段，由校验脚本强制检查（缺注音直接报错）；
- 前端：`getPet(id).pinyin` 取用，名称牌 / 图鉴 / 抽卡结果共用同一个字段，不在组件里写死拼音；
- 样式：注音放在名称正下方，字号 11px、颜色 `--ink-3`，可小但不可省；
- 学生造物（无极）：名称由学生自己填，**教师审核时一并确认读音与含义**，写入 `custom_pets.pinyin`。

> **产品层的配套**（对留存的影响常大于画功）：可换装的角色皮肤、摸头/喂食的宠物互动、贴纸化的图鉴、给宠物起名（15 分改名）。四件事覆盖了萌系用户最在意的"陪伴感"。
