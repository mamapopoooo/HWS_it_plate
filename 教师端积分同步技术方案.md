## 2. 推荐方案：实时 API 调用

### 2.1 为什么选实时？

| 对比项 | 实时 API | 定时同步 |
|--------|----------|----------|
| 延迟 | 0秒 | 1天/1小时 |
| 复杂度 | 中（需写API调用代码） | 低（定时任务） |
| 可靠性 | 依赖网络 | 本地文件更可靠 |
| 体验 | 学生立即看到 | 有延迟 |
| 适用场景 | 课堂即时反馈 | 批量处理 |

**结论：** 教师端是 Python 程序，调用 HTTP API 很简单，实时同步体验最好。

### 2.2 备用方案：离线缓存 + 定时补偿

如果网络不稳定，可以：
1. 教师端加减分后，先写入本地 JSON 文件
2. 同时尝试调用 API
3. 如果 API 失败，数据保留在本地
4. 定时任务（每小时/每天）重新同步本地数据

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | ✅ | 记录唯一ID（建议格式：`rec_YYYYMMDD_序号`） |
| timestamp | integer | ✅ | 时间戳（毫秒） |
| teacher_id | string | ✅ | 教师ID |
| student_id | string | ✅ | 学生ID（与网页端一致） |
| student_name | string | ❌ | 学生姓名（便于查看） |
| amount | integer | ✅ | 分值（正数加分，负数扣分） |
| reason | string | ✅ | 原因 |
| category | string | ✅ | 分类：answer/homework/test/discipline/other |
| synced | boolean | ✅ | 是否已同步到网页端 |
| synced_at | integer | ❌ | 同步时间戳（成功时填写） |

### 3.2 学生身份关联

2. 教师端使用相同的ID
3. 首次使用时，教师端从网页端下载学生名单（CSV/JSON）

### 4.1 网页端新增 API

#### A. 提交积分记录（教师端调用）

```http

      "studentId": "stu_2026001",
      "amount": 3,
      "reason": "回答问题正确",

{
  "success": true,
  "processed": 1,
  "failed": 0,
  "results": [
    {
      "recordId": "rec_20261102_001",
      "status": "success",
      "newTotal": 45
    }
```

**处理逻辑：**
1. 验证教师身份（Token）
2. 检查记录ID是否重复（防止重复提交）
3. 为每个学生更新积分总额
4. 记录积分历史
5. （可选）自动转化为宠物经验

### 4.2 错误处理

| 错误码 | 说明 | 教师端处理 |
|--------|------|------------|
| 400 | 参数错误 | 检查数据格式 |
| 401 | Token 无效 | 提示教师重新登录 |
| 409 | 记录ID重复 | 跳过该记录（已同步） |
| 500 | 服务器错误 | 保留本地数据，稍后重试 |

## 5. 教师端 Python 代码示例

### 5.1 核心模块

```python
# teacher_app/points_sync.py

import json
import requests
import time
from pathlib import Path
from typing import List, Dict

class PointsSync:
    def __init__(self, api_base_url: str, teacher_token: str):
        self.api_base = api_base_url
        self.token = teacher_token
        self.data_file = Path("data/points_records.json")
        self.data_file.parent.mkdir(exist_ok=True)
        
    def add_points(self, student_id: str, amount: int, reason: str, category: str):
        """教师端加减分操作"""
        record = {
            "id": f"rec_{int(time.time())}_{student_id[-4:]}",
            "timestamp": int(time.time() * 1000),
            "student_id": student_id,
            "amount": amount,
            "reason": reason,
            "category": category,
            "synced": False,
            "synced_at": None
        }
        
        # 保存到本地
        self._save_to_local(record)
        
        # 尝试同步到网页端
        success = self._sync_to_server(record)
        
        if success:
            record["synced"] = True
            record["synced_at"] = int(time.time() * 1000)
            self._update_local_record(record)
        
        return success
    
    def _save_to_local(self, record: Dict):
        """保存记录到本地JSON文件"""
        if self.data_file.exists():
            with open(self.data_file, 'r', encoding='utf-8') as f:
                data = json.load(f)
        else:
            data = {"records": []}
        
        data["records"].append(record)
        
        with open(self.data_file, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
    
    def _sync_to_server(self, record: Dict) -> bool:
        """同步单条记录到网页端API"""
        try:
            url = f"{self.api_base}/api/game/points/submit"
            headers = {
                "Authorization": f"Bearer {self.token}",
                "Content-Type": "application/json"
            }
            payload = {"records": [record]}
            
            response = requests.post(url, json=payload, headers=headers, timeout=5)
            
            if response.status_code == 200:
                result = response.json()
                return result.get("success", False)
            else:
                print(f"同步失败: {response.status_code} - {response.text}")
                return False
                
        except requests.exceptions.RequestException as e:
            print(f"网络错误: {e}")
            return False
    
    def sync_pending_records(self):
        """同步所有未同步的记录（定时任务调用）"""
        if not self.data_file.exists():
            return
        
        with open(self.data_file, 'r', encoding='utf-8') as f:
            data = json.load(f)
        
        pending = [r for r in data["records"] if not r["synced"]]
        
        if not pending:
            print("没有待同步的记录")
            return
        
        print(f"开始同步 {len(pending)} 条记录...")
        
        for record in pending:
            success = self._sync_to_server(record)
            if success:
                record["synced"] = True
                record["synced_at"] = int(time.time() * 1000)
        
        # 更新本地文件
        with open(self.data_file, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        
        print(f"同步完成: {len(pending)} 条")
    
    def _update_local_record(self, updated_record: Dict):
        """更新本地记录的同步状态"""
        with open(self.data_file, 'r', encoding='utf-8') as f:
            data = json.load(f)
        
        for i, record in enumerate(data["records"]):
            if record["id"] == updated_record["id"]:
                data["records"][i] = updated_record
                break
        
        with open(self.data_file, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)


# 使用示例
if __name__ == "__main__":
    sync = PointsSync(
        api_base_url="http://110.40.142.247:3002",
        teacher_token="your_teacher_token_here"
    )
    
    # 教师加减分
    success = sync.add_points(
        student_id="stu_2026001",
        amount=3,
        reason="回答问题正确",
        category="answer"
    )
    
    if success:
        print("积分已同步到网页端")
    else:
        print("同步失败，数据已保存到本地，稍后重试")
    
    # 定时任务：同步所有未同步的记录
    # sync.sync_pending_records()
```

### 5.2 定时任务（可选）

```python
# teacher_app/scheduler.py

import schedule
import time
from points_sync import PointsSync

sync = PointsSync(
    api_base_url="http://110.40.142.247:3002",
    teacher_token="your_teacher_token_here"
)

# 每小时同步一次未同步的记录
schedule.every(1).hours.do(sync.sync_pending_records)

# 每天凌晨2点全量同步
schedule.every().day.at("02:00").do(sync.sync_pending_records)

print("定时任务已启动...")

while True:
    schedule.run_pending()
    time.sleep(60)
```

## 6. 网页端 API 实现（Express）

### 6.1 数据库表扩展

```sql
-- 积分记录表（新增）
CREATE TABLE IF NOT EXISTS points_records (
  id TEXT PRIMARY KEY,
  student_id TEXT NOT NULL,
  teacher_id TEXT,
  amount INTEGER NOT NULL,
  reason TEXT,
  category TEXT,
  created_at INTEGER,
  FOREIGN KEY (student_id) REFERENCES users(id)
);

-- 学生积分总额（新增字段到 users 表）
ALTER TABLE users ADD COLUMN total_points INTEGER DEFAULT 0;

-- 索引
CREATE INDEX IF NOT EXISTS idx_points_student ON points_records(student_id, created_at DESC);
```

### 6.2 API 路由实现

```javascript
// server/routes/points.js

import { Router } from 'express'
import { db } from '../db.js'

const router = Router()

// 提交积分记录（教师端调用）
router.post('/submit', requireAuth, requireRole('teacher', 'admin'), (req, res) => {
  const { records } = req.body
  if (!records || !Array.isArray(records)) {
    return res.status(400).json({ error: '缺少 records 数组' })
  }
  
  const results = []
  let processed = 0
  let failed = 0
  
  for (const record of records) {
    try {
      // 检查是否已存在（防止重复提交）
      const existing = db.prepare('SELECT id FROM points_records WHERE id = ?').get(record.id)
      if (existing) {
        results.push({ recordId: record.id, status: 'duplicate', message: '记录已存在' })
        continue
      }
      
      // 插入积分记录
      db.prepare(`
        INSERT INTO points_records (id, student_id, teacher_id, amount, reason, category, created_at)
        VALUES (?, ?, ?, ?, ?, ?, ?)
      `).run(
        record.id,
        record.studentId,
        req.user.id,
        record.amount,
        record.reason,
        record.category,
        record.timestamp
      )
      
      // 更新学生积分总额
      db.prepare(`
        UPDATE users SET total_points = total_points + ? WHERE id = ?
      `).run(record.amount, record.studentId)
      
      // 获取新的积分总额
      const student = db.prepare('SELECT total_points FROM users WHERE id = ?').get(record.studentId)
      
      results.push({
        recordId: record.id,
        status: 'success',
        newTotal: student.total_points
      })
      processed++
      
    } catch (error) {
      console.error('处理积分记录失败:', error)
      results.push({
        recordId: record.id,
        status: 'error',
        message: error.message
      })
      failed++
    }
  }
  
  res.json({
    success: failed === 0,
    processed,
    failed,
    results
  })
})

// 查询学生积分
router.get('/student/:studentId', requireAuth, (req, res) => {
  const student = db.prepare(`
    SELECT id, real_name, total_points FROM users WHERE id = ?
  `).get(req.params.studentId)
  
  if (!student) {
    return res.status(404).json({ error: '学生不存在' })
  }
  
  const history = db.prepare(`
    SELECT pr.*, u.real_name as teacher_name
    FROM points_records pr
    LEFT JOIN users u ON pr.teacher_id = u.id
    WHERE pr.student_id = ?
    ORDER BY pr.created_at DESC
    LIMIT 100
  `).all(req.params.studentId)
  
  res.json({
    studentId: student.id,
    studentName: student.real_name,
    totalPoints: student.total_points,
    history
  })
})

// 班级排行榜
router.get('/class/:classId/ranking', requireAuth, (req, res) => {
  const limit = parseInt(req.query.limit) || 50
  
  const rankings = db.prepare(`
    SELECT 
      u.id as student_id,
      u.real_name as student_name,
      u.total_points,
      RANK() OVER (ORDER BY u.total_points DESC) as rank
    FROM users u
    WHERE u.class_id = ?
    ORDER BY u.total_points DESC
    LIMIT ?
  `).all(req.params.classId, limit)
  
  res.json({
    classId: req.params.classId,
    rankings
  })
})

export default router
```

### 7.2 兑换 API

```javascript
// POST /api/game/points/redeem
router.post('/redeem', requireAuth, requireRole('student'), (req, res) => {
  const { itemId, studentId } = req.body
  
  const student = db.prepare('SELECT total_points FROM users WHERE id = ?').get(studentId)
  
  const items = {
    'exp_100': { cost: 10, type: 'exp', value: 100 },
    'egg_random': { cost: 50, type: 'egg' },
    'skill_reset': { cost: 30, type: 'reset' }
  }
  
  const item = items[itemId]
  if (!item) return res.status(400).json({ error: '无效商品' })
  
  if (student.total_points < item.cost) {
    return res.status(400).json({ error: '积分不足' })
  }
  
  // 扣除积分
  db.prepare('UPDATE users SET total_points = total_points - ? WHERE id = ?')
    .run(item.cost, studentId)
  
  // 根据商品类型处理
  if (item.type === 'exp') {
    // 给所有宠物加经验
    const pets = db.prepare('SELECT id FROM player_pets WHERE user_id = ?').all(studentId)
    for (const pet of pets) {
      // 调用加经验的逻辑
      addPetExp(pet.id, item.value)
    }
  } else if (item.type === 'egg') {
    // 发放随机宠物蛋
    grantRandomEgg(studentId)
  }
  
  res.json({ success: true, newTotal: student.total_points - item.cost })
})
```
